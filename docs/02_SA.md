## 3. Domain Entities

Project / Task / Run / Actor / WorkflowDefinition / WorkflowVersion / RoleProfile / ContextPackage / Artifact / Finding / Evidence / Decision/Verdict / Extension / Manifest / Capability / ExecutionTarget / PolicyDecision / RunEvent / SecretRef。

Vendor raw session/output 可保存為 Raw Artifact，但不可成為核心 Domain schema。

### 3.1 Task / Run Semantic Boundary

- `Task != Run`。
- 一個 Task 可以有多個 Run。
- Run 是目前 durable execution identity。
- 本 baseline 不將 `Run == Attempt` frozen，也不新增 Attempt entity。Retry、fallback、resume attempt 的一般化語意維持 deferred；只有實際需求證明一個 logical Run 需要多個 independently identifiable attempts 時，才重新進入 Architecture Gate。

## 5. Integration Classes & Maturity

Integration Class：Native Runtime / Standard Agent Protocol / Framework-Harness Runtime / Model Endpoint / Web AI Surface。

Maturity：CERTIFIED / SUPPORTED / PREVIEW / EXPERIMENTAL / DETECTED / INCOMPATIBLE。

Broad compatibility 不等於 broad certification。

## 7. Run Lifecycle Analysis

Normalized state：CREATED → STARTING → RUNNING → COMPLETED / FAILED / TIMED_OUT / CANCELLED。
Cancellation path：RUNNING → CANCEL_REQUESTED → CANCELLED。
`ORPHANED` 僅為診斷異常，不視為正常完成。

Timeout 必須重用 cancellation/cleanup pipeline。

Resume：NATIVE / MANAGED / NONE；Managed resume 由 PolyNexus 以 checkpoint/context continuation 建立新 Run。

## 8. Execution Target

V1 implementation：`LOCAL`。
Domain 預留：`PERSONAL_NODE` / `REMOTE_SERVER`，但不實作 distributed queue/worker farm。

## 9. Local Model Contract

Health / Auth Readiness / Model Discovery / Selection / Submit / Streaming / Result / Timeout / Cancel capability / Structured Output capability / Error Normalization / Usage metadata / Evidence / Version+Model Identity。

Capability 按 Endpoint + Model 宣告。

### 9.1 Durable Execution Provenance Requirement

Durable execution 必須保留未來能確定實際 execution environment 的能力；適用資訊包含 runtime identity/version、adapter version、model identity/version、execution target、effective capability profile 與 policy profile。現階段優先重用 `RuntimeCapabilities`、`runtime_ref`、`version_info()`、`execution_target` 與 `ResumeMode`，不建立 `RuntimeBindingSnapshot` 或第二套 Runtime Selection Metadata。若未來需要 persisted runtime binding，必須先提出 `ARCHITECTURE_DECISION_REQUIRED`。

## 10. Workflow Analysis

Workflow 是 state machine；AI 是 node，不是 owner。

Authoring：YAML。
Validation：JSON Schema。
Runtime：Canonical WorkflowDefinition。

V1 Nodes：CONTEXT / AI_TASK / PARALLEL_AI / CROSS_REVIEW / TOOL / EVIDENCE_CHECK / HUMAN_GATE / SYNTHESIS / limited CONDITION。

不支援任意 Python/JavaScript/while/for/general BPM DSL。

## 11. Data Classification & Egress

Effective Classification = Project / Task / selected Artifact 中最高級別。
外傳前檢查 classification + execution mode + destination/tool trust + side-effect risk。

Local Model 不等於 Local Workflow；外部 Tool/Connector 仍構成 egress。

## 12. Storage Analysis

SQLite：metadata/state/index/small structured records。
Filesystem：documents/logs/diffs/screenshots/reports/raw outputs/evidence files。
Artifact metadata 包含 SHA-256/hash identity。
Context Package 使用 reference manifest，不重複複製 Artifact。

Runtime Data 預設不放使用者 Source Git Tree。

## 13. Secret Boundary

Domain 只保存 `SecretRef`，不保存 Secret value。Secret value 由 OS-backed SecretStore implementation 管理。

Secret value 禁止進 DB Domain table、Event Ledger、Evidence、Artifact、Logs、Export、Backup、Git、Handoff、Telemetry。

Credential / Execution Permission / Data Policy 是三個獨立控制面。

## 14. Browser Companion Boundary

Chrome MV3 Thin Companion：Service Worker + Site Drivers。Vendor DOM/selector 不進 Core。

Companion ↔ Core：authenticated loopback API，bind 127.0.0.1；pairing/token/caller validation。Driver failure 必須可 fallback 到 manual handoff，且不得使 Core unavailable。

## 15. Event & Audit

Durable：task/run lifecycle、finding、evidence、approval、decision、migration、human override。
Live-only possible：token stream、progress pulse、transient process detail。

## 16. Non-functional Requirements

Reliability：adapter/driver failure isolation；process-tree cleanup。
Maintainability：新增 compatible Runtime 以 adapter + manifest + conformance 為主。
Security：least privilege、no secret leakage、local-only fail closed、loopback auth。
Performance：基本 queue/concurrency/timeout；不做 distributed scheduler。
Migration：schema_version + migration + backup gate。
Token/Quota：need-to-know context、delta handoff、machine-filter-first。

Error Contract：錯誤必須可被 machine-classifiable；retryability 不得從任意文字推定，human-required condition 必須能與 retryable runtime failure 區分。本輪不 frozen 完整 error taxonomy。

Compatibility：persisted 或 externally exchanged contract 在引入 incompatible producer 前，必須定義 compatibility/version strategy；不要求所有現有 dataclass 立即新增 `schema_version`。

Restart：real-runtime production readiness 前，Core 必須為 non-terminal durable Runs 定義 deterministic restart reconciliation。本要求不代表目前已實作 crash reconciler。

## 17. Communication / Transport / Gateway Boundary

`Communication Contract First. Transport Second.` Task/Result handoff 優先使用既有 Task、Handoff、Artifact、Evidence、ContextPackage references 加 current delta；TaskPacket／ResultPacket 僅是 communication mapping view，不是第二套 persisted Domain。

Manual Copy、Shared File、Git、CLI、REST、MCP、A2A 都只是 transport candidate，不得成為核心 communication semantics。`Communication Contract != GitHub`；GitHub 是 development collaboration infrastructure，不是 Product Core dependency。

`Provider / Model Gateway != PolyNexus Coordination Plane`。OmniRoute、LiteLLM、OpenRouter 或 Direct Provider 只能作未來 optional integration；PolyNexus 不重新實作 Provider Gateway。
