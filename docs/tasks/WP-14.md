`RuntimeAdapter` Protocol (ADR-007 lifecycle + PRE-WP14-A cleanup contract), with
targeted conformance tests for lifecycle, cancel, timeout cleanup, result/error

## Scope implemented (exact allowlist)

- NEW `services/core/src/polynexus_core/runtime/codex.py`: `CodexRuntimeAdapter`
  - Full Protocol surface: health/readiness/capabilities/create_run/submit/
    status/result/cancel/resume/artifacts/cleanup/version_info.
   - Stable `codex:<32-hex>` runtime refs; CREATED -> RUNNING on submit;
     double-submit and wrong-state result fail closed.
   - Cancel stops only active states (CREATED/STARTING/RUNNING -> CANCELLED);
     terminal states (including TIMED_OUT) stay unchanged so the shared
     `_cleanup_and_verify()` machinery observes the expected post-cleanup state.
   - Timeout path: driver hook `simulate_timeout()` sets TIMED_OUT from RUNNING;
     supervisor cancel->cleanup->status verification yields TIMED_OUT with
     cleanup verified, or fail-closed ORPHANED on any failure.
    - Error normalization: FAILED runs expose only the constant
      "Codex runtime reported execution failure"; raw vendor/exception text is
      never stored or echoed. Unknown references raise sanitized KeyError without
      echoing caller input; `_get()` rejects `type(runtime_ref) is not str` before
      any dict lookup, then `dict.get` + single constant raise, so `__cause__ is None`,
      `__context__ is None`, and formatted traceback contains no caller-controlled material.
  - Truthful capabilities: cancel=True, resume=NONE (never fakes native resume),
    artifacts=True, timeout_cleanup_verified=True (backed by targeted evidence),
    usage_visibility=UNAVAILABLE, auth_ownership=NONE (no credential storage).
  - version identity: stable `codex-local-adapter/0.1`.
  - Retains only caller-provided ContextPackage/Task references (contract-
    mandated); derives no new durable surface containing their content.
- NEW `services/core/tests/test_wp14_codex_runtime.py`: 31 deterministic tests (25 + 6 poisoned-subclass)
  covering Protocol conformance, capabilities/version truthfulness, lifecycle,
  stable IDs, double-submit rejection, supervisor completion, user-cancel with
  verified cleanup, timeout cleanup success, timeout/cancel failure paths
  (cancel raises / cleanup raises / cleanup False -> ORPHANED; `_CleanupFalseCodex`
  retains `await super().cleanup` with no warning suppression), normalized
  failure error sanitization, unknown-ref fail-closed without echo (expanded to
  check `str`, `args`, `__cause__ is None`, `__context__ is None`, and
  `traceback.format_exception` for each of status/result/cancel/cleanup/
  artifacts/resume), poisoned `str`-subclass coverage (all 6 methods, str/repr/__cause__/__context__/traceback, plus valid exact-string retained as CREATED), resume=NotImplementedError, artifacts never fabricated,
