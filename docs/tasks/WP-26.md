## Scope

- Progressive disclosure for metadata and work-mode guidance.
- Keyboard-visible skip navigation and focus-visible controls.
- Consistent loading, empty, retryable error, permission, Human-required, and
  terminal-state messaging across project, task, run preparation, and run
  detail views.
- Clear stale data on retry and generic user-facing errors that do not expose
  raw server bodies.

## Implementation

`apps/web/src/components/StatusMessage.tsx` centralizes status semantics and
ARIA roles. Project/task/run components use it for explicit state rendering;
`RunDetail` distinguishes Human-required states from terminal failures without
inferring success or evidence. `App.tsx` adds the skip target and
`styles.css` provides visible focus treatment.
