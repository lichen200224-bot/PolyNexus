## Scope and acceptance

- Enforce bounded per-operation timeout, per-run operation budget, and global
  runtime-operation concurrency.
- Reuse one cleanup/verification path for timeout and cancel.
- Fail closed to `TIMED_OUT` when cleanup is verified and to `ORPHANED` when
  cleanup cannot prove the owned resource stopped.
- Isolate adapter/setup failures and clean a runtime reference allocated before
  a later workflow setup failure.
