# WP-17 — LocalModelEndpoint profiles

## Scope

Internal deterministic acceptance for loopback local model profiles:
LM Studio, Ollama, and generic OpenAI-compatible endpoints. This work keeps
endpoint and vendor protocol details inside `LocalModelEndpointAdapter` and
does not add a Domain entity, migration, credential store, or cloud fallback.

## Acceptance criteria

- Detects model identity from the profile-specific model listing shape.
- Supports the OpenAI-compatible `/v1` protocol and Ollama `/api` protocol;
  LM Studio remains an OpenAI-compatible profile.
- Normalizes create/submit/status/result/error and exposes truthful timeout,
  cancel, cleanup, resume, artifact, usage, and auth capabilities.
- Rejects non-loopback, credential-bearing, redirected, malformed, or
  over-sized endpoint traffic without echoing endpoint values.
- Timeout produces a terminal `TIMED_OUT` state; cleanup remains unverified
  when an already-accepted HTTP request cannot be cancelled safely.
