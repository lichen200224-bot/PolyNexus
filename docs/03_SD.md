## 3. Run State

```text
CREATED
  -> STARTING
  -> RUNNING
      -> COMPLETED
      -> FAILED
      -> TIMED_OUT
      -> CANCEL_REQUESTED -> CANCELLED
```

`ORPHANED` = cleanup verification failed diagnostic state。

Final state immutable。Timeout 與 user cancel 共用 terminate/cleanup machinery，但保留不同 reason/evidence。

## 4. Run Supervisor Responsibilities

- process/session ownership
- stable run id mapping
- timeout
- graceful cancel
- process-tree terminate/kill fallback
- child/resource cleanup verification
- normalized status/error
- artifact/evidence collection hooks
- execution target abstraction (`LOCAL` in V1)

Adapter 負責 vendor-specific invocation/session semantics；Core 不散落 `if provider == ...`。

## 12. Repository Interfaces

ProjectRepository / TaskRepository / RunRepository / WorkflowRepository / EvidenceRepository / ArtifactRepository / DecisionRepository / ExtensionRepository / EventRepository。

Domain service 不直接散落 SQL。

### 12.1 Migration Authority

Alembic 是 authoritative schema migration mechanism。`SQLAlchemy Base.metadata.create_all()` 不得被視為 production migration policy。本文件不修改現有 startup/bootstrap 行為；其用途（development bootstrap、tests、local initialization 或 production startup）必須由獨立 product hardening task 以 source 與 deterministic evidence 驗證後再調整。

### 12.2 Configuration Precedence Ownership

任何新增 configuration source 都必須先指定 owner、scope、precedence、secret boundary 與 compatibility impact，不能靠載入順序或任意 fallback 隱式決定。若現有 source 尚未定義完整 precedence，應由獨立 contract/hardening task 先盤點實際行為；本治理 patch 不改變 runtime configuration behavior。

## 18. Human-Accepted Runtime Binding Design — NOT IMPLEMENTED

The Human-accepted but unimplemented ADR-011 resolution path extends existing Supervisor/Adapter boundaries without introducing a second execution identity:

```text
RuntimeProfile (mutable execution intention)
  -> RuntimeRegistry / AdapterFactory
  -> Run-owned immutable RuntimeBindingSnapshot
  -> RuntimeAdapter
  -> existing RunSupervisor
```

| Concept | Accepted architecture meaning |
|---|---|
| Provider | Supplying ecosystem; validated opaque `provider_id` |
| TransportKind | `LOCAL`, `NATIVE_SUBSCRIPTION`, `OFFICIAL_API`, or boundary-only `WEB_INTERACTIVE` |
| Runtime | Actual execution environment; validated opaque `runtime_id` |
| Adapter | PolyNexus normalized implementation; opaque `adapter_id` and version |
| ExecutionTarget | Existing supervision location; V1 remains `LOCAL` |

Snapshot identity is fixed before real execution, owned by the existing Run, persisted only after separate ADR/migration approval, and never reconstructed from mutable RuntimeProfile configuration. Planned Alembic `0002` requires deterministic legacy/reference backfill, reload immutability, rollback/restore evidence and independently approved source/test scope.

If future Workflow selection is separately approved, only `runtime_profile_ref` may cross the fixed ADR-009 boundary. Raw credentials, vendor CLI arguments, cookies, session tokens, private endpoints and Provider-specific Core branches remain prohibited. WebSurface remains under ADR-006; capability and usage claims must reflect actual evidence.

`docs/30_RUNTIME_CONTRACT_FOUNDATION_GATE.md` defines independent `PRE-WP14-A` lifecycle/cleanup and `PRE-WP14-B` binding/migration gates. This section does not implement or accept either gate.
