# G0/B01 evidence redaction receipt

Publication source: G0 fresh command logs from Codex task `01a0a4f7-6bcd-7160-930d-22c233db3134` and B01 final3 raw artifacts from task `01a09fe7-12e2-7c61-aa3e-fcbc0543de45`. `COMMAND_LEDGER.json` cites original command item IDs and actual tool exits. Raw logs and JSON/JSONL are copied in their original record order.

Deterministic transformation: decode each source file as UTF-8, replace case-insensitive literal personal home prefixes `C:\Users\<PERSONAL_USERNAME>` (including JSON-escaped backslash forms) and `C:/Users/<PERSONAL_USERNAME>` with `<USER_HOME>`, then write UTF-8 without BOM. The same replacement is applied inside JSON string values, JSONL command/output fields, logs, and ledger command/cwd values. No JSON values are parsed and rewritten for the raw copies. `COMMAND_LEDGER.json` is a separate transcription of recorded command events; its `command` and `cwd` undergo only that home-prefix normalization.

Affected raw fields include `source_repo`, `artifact_root`, `generated_evidence`, `actual_cwd`, `executor`, `wrapper_cwd`, `stdout_path`, `stderr_path`, `pytest_runner_cwd`, `accepted_worktree`, `package`, and process record `cwd`/path arrays. The JSONL `command`, `aggregated_output`, and file-change `path` retain their contents apart from the same prefix replacement. Web Vitest's forward-slash cwd was normalized too. No other field was redacted. Scan of the original selected source files found no API key, token, cookie, credential, private key, Human WebAuthn material, or secret value requiring removal.

No exit code, state, hash, test count, failure message, runtime result, source diff, or acceptance meaning was changed. The first full-Core `exit 1` and its three backup-path failures, as well as the two initial npm install failures, remain published. The one Core skip remains `SKIPPED`: `services/core/tests/test_d2a_external_runtime.py::test_projected_staging_rejects_nested_reparse_path` calls `pytest.skip("symlink creation is unavailable in this Windows test environment")` when Windows symlink creation raises `OSError`.

`HISTORICAL_P0_ZIP_DIRECT_BYTE_CHECK=NOT_VERIFIED`. The historical zip bytes were not directly checked by this publication. The sanitized `p0-reconstruct.json` records the fresh B01 verify/reconstruct test observation and does not upgrade the historical zip check.

`.gitattributes` disables Git text conversion and inherited terminal whitespace checks for this evidence directory, preserving raw log/JSONL bytes while allowing `git diff --check` to verify the remaining changed paths. `MANIFEST.sha256` covers every other published evidence file, including this receipt and the ledger. It does not hash itself, because a self-hash cannot be represented as a stable SHA-256 manifest entry.
